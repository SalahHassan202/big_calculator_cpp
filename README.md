# 🚀 big_calculator_cpp

## 🚀 About This Repository:
This repository contains the code for a big calculator built using C++. The calculator allows the user to perform various mathematical operations, including addition, subtraction, multiplication, division, modulus, squaring, square root, checking even or odd numbers, calculating powers, generating tables of numbers or strings, and calculating determinants of 2D and 3D matrices. It features a menu-driven interface for easy operation selection.
